# 작업 기록

- `scaffolding/summary.md`: 구성 결정, 변경 파일, 실행한 검사와 미검증 범위. 새 세션의 시작점이다.
- 후속 작업은 `work/<work-id>/summary.md`에 요청, 변경 범위, 작성자, 검사 결과와 다음 행동을 기록한다. 이전 작업 기록을 덮어쓰지 않는다.
- 실제 세션·모델 인계 시에만 같은 작업 폴더에 `STATUS.md`, `HANDOFF.md`를 추가하고 읽을 순서와 미완료 항목을 남긴다.

검증 결과는 실제 실행 근거를 기록한다. 단일 실행에 팀이나 역할 파일을 강제하지 않는다.
