# T07 재작업 재리뷰 - 썸네일 로드 대기

- 비교 기준: 현재 `HEAD` 대비 `src/components/common/project-card-thumbnails.tsx` 미커밋 diff
- 검토 범위: 이전 High(E-h) 해결 여부와 이번 수정 diff가 새로 만든 문제
- 판정: **재작업 diff 통과**
- 자체 리뷰: 새 finding 없음

## 이전 High 해결 확인

이전에는 4초 타이머가 로드 상태와 관계없이 인덱스를 바꾸고, 600ms 뒤 이전 이미지를 내렸다. 수정 후 `loaded`에 프레임 로드 완료를 기록하고, 4초 간격이 끝난 뒤 `nextIndex`가 선택한 프레임까지 로드됐을 때만 `advance`를 실행한다. 따라서 다음 프레임이 늦게 로드되면 현재 프레임을 계속 보여 주며, 이전 High는 해결됐다.

탭 비활성·화면 밖·호버·포커스 상태에서 `active`가 꺼지면 경과 상태를 초기화하고, 다시 활성화될 때 새 4초 간격을 시작한다. 다음 이미지 로드 대기 상태에서도 기존 간격 타이머가 중복 생성되지 않는다.

## 새 문제 점검

- 로드 성공 시에만 전환하고, 오류 프레임은 `failed` 집합에서 제외한 뒤 다음 정상 후보를 기다리는 흐름이 기존 `nextIndex`와 맞는다.
- 로드 대기 중 일시정지되면 대기 중인 경과 상태도 초기화되므로, 재개 직후 전환하지 않는다.
- diff에서 새로 발견한 회귀나 추가 수정 요청은 없다.
