# 개선 기록

## 세션 간 인계와 마무리

- Codex 세션에서 사용자가 붙여 넣은 대화 기록으로 이어받음. 인계 문서(`handoff.md`)는 구현 전 상태라 실제 작업 트리·리뷰 산출물·triage를 우선 근거로 사용.
- Codex가 메인 체크아웃 밖(`/private/tmp`)에 만든 재작업 worktree는 메인 반영 후에도 남아 있었음. 제거 전 파일 단위 비교로 메인이 상위 집합임을 확인.
- 적용된 미커밋 마이그레이션(0007)을 직접 고치면 `scripts/migrate.mjs`가 `created_at` 기준으로 재실행하지 않아 E2E DB와 어긋남. 새 마이그레이션(0008)으로 추가 변경을 분리.
- 자동 재시도 방식은 배포 설정(cron·환경변수) 유무가 갈리는 결정이라 구현 전 사용자에게 확인.
- 단위 테스트 DB 대역이 SQL 조건을 실행하지 못해 "참조 보호"는 대역 결과로만 표현됨. 실제 보호 동작은 opt-in DB 통합 테스트가 담당.
