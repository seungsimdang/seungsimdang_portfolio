# 개선 기록

## T09 재개와 전달

- 재개 요청에서 최신 triage까지 먼저 읽고, 과거 결정 대기 문구보다 문서 뒤에 추가된 사용자 결정과 반영 기록을 우선 확인.
- 실제 소스를 import하는 폼 스키마·서버 오류 매핑 회귀 테스트를 QA가 작성. 비공개 `inputName`은 공개 `applyServerErrors`가 호출하는 실제 경로로 검증하고 테스트용 export 확장 생략.
- 사용자 개발 서버의 `.next`를 보존하기 위해 `/private/tmp` 복사본과 3100번 독립 서버에서 브라우저 확인. 테스트용 인증값과 별도 E2E DB 사용.
- 실제 부분 저장 검증은 E2E DB에서 이름만 변경하고 다른 컬럼 보존을 확인한 뒤 원복. `updated_at`과 쓰기 제한 기록의 시각은 테스트 실행으로 갱신.
- 하네스만 먼저 커밋하려던 시도는 React Doctor의 인덱스·작업 트리 `package.json` 불일치 검사로 차단. RHF 의존성과 기능을 먼저 커밋하고 하네스를 뒤에 분리해 훅 우회 없이 해결.
- 임시 복사본에서 `pnpm exec`가 의존성 재설치를 시도하므로 기존 `node_modules`의 CLI를 직접 실행. 파일·포트 접근 제한은 필요한 명령만 권한 확장으로 재시도.
- 최종 리뷰 뒤 승인된 Low 수정은 기존 orchestrator 규칙에 따라 재리뷰를 생략하고 T09 검증과 Git 훅으로 확인.
