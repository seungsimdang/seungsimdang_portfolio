# 버그 리포트 20261015145447

## 요약
- 심각도: Low (모바일 관리자 헤더에서 로그아웃 버튼이 별도 행을 차지해 헤더 높이와 본문 시작 위치가 커짐)
- 중복 여부: 신규 (기존 admin 저장 피드백, 이미지 fill 경고, CI 관리자 E2E 인증 티켓과 증상이 다름)

## 재현 단계
1. 모바일 너비에서 관리자 로그인 후 관리자 콘솔 페이지를 연다.
2. 이름, 메뉴, 로그아웃 버튼이 표시된 상단 헤더를 확인한다.

## 기대 동작
모바일에서 로그아웃 버튼이 관리자 이름과 같은 첫 줄의 오른쪽에 표시되고, PC 뷰의 헤더 배치에는 영향이 없다.

## 실제 동작
제공된 모바일 화면에서 로그아웃 버튼이 메뉴 아래 별도 행에 표시되어 헤더 공간을 차지한다.

## 환경 정보
- 관련 파일: `src/components/admin/admin-console-shell.tsx`, `src/components/admin/admin-nav.tsx`, `src/components/admin/sign-out-button.tsx`
- 관찰 근거: 사용자 제공 모바일 화면. 브라우저·기기·뷰포트 값은 미확인.
- 코드 관찰: `AdminConsoleShell`은 이름과 메뉴·로그아웃 그룹을 `admin-header-content` 안에 두며, 그룹 내부 `AdminNav`가 기본 모바일 너비에서 `w-full`이다. 실제 줄바꿈 동작은 브라우저에서 재현하지 않음.

## 확인 필요
- 모바일에서 이름과 로그아웃 버튼이 첫 줄에 놓이고 메뉴가 다음 줄에 유지되는지 확인.
- PC 뷰 헤더 배치가 기존과 같은지 확인.
- 좁은 모바일 화면에서도 버튼이 이름과 겹치지 않고 터치 가능한 크기를 유지하는지 확인.
