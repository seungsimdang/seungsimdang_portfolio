# 수정 요약 T03

## 수정 파일 목록
| 파일 | 변경 내용 |
|------|-----------|
| `src/app/globals.css` | 767px 이하 관리자 헤더에서 로그아웃을 이름 오른쪽에 두고 메뉴를 다음 줄로 이동 |

## 수정 내용
### `src/app/globals.css`
- 변경 전: 모바일에서 관리자 메뉴의 `w-full` 너비가 액션 그룹을 감싸며 로그아웃이 별도 행으로 밀림.
- 변경 후: 767px 이하에서만 액션 래퍼를 `display: contents`로 처리하고 메뉴에 전체 행과 다음 순서를 적용, 로그아웃 링크에 자동 왼쪽 여백을 적용.
- 768px 이상 규칙과 컴포넌트 DOM은 변경하지 않음.

## 검증
- 빌드/타입 검사 결과: Biome CSS 검사 통과 (`node_modules/.bin/biome check src/app/globals.css`). 메인 orchestrator의 `pnpm type-check` 통과.
- 동일 패턴 잔존 여부: 같은 관리자 헤더 셀렉터는 이 스타일 블록 외에 없음. 모바일 메뉴는 다음 행, 로그아웃은 첫 행 오른쪽에 배치됨.
- `pnpm exec biome check`는 공유 `node_modules` symlink에서 pnpm이 모듈 디렉터리 정리를 시도해 TTY 없이 중단됨. 설치 상태는 변경되지 않았고, 설치된 Biome 바이너리 직접 실행으로 검사 완료.

## 미해결 항목
- 실제 로그아웃 실행 및 프로덕션 배포는 수행하지 않음.

## 메인 반영 후 검증
- 승인된 CSS diff만 메인에 반영하고 독립 worktree를 정리함. 제공 도구에 `Agent(isolation: worktree)`가 없어 detached 임시 git worktree와 diff 반영으로 대체함. 커밋/푸시는 하지 않음.
- 인증된 localhost:3000 관리자 화면에서 320/360/390/767/768/810/1024/1440px 확인. 767px 이하 이름과 로그아웃이 같은 줄이고 메뉴는 아래에 배치됨. 가로 넘침 없음, 로그아웃 높이 44px 유지.
- 390px 헤더 높이: 165px -> 129px. `/private/tmp/logout-before-390.png`, `/private/tmp/logout-after-390.png` 시각 확인.
- 768/810/1024/1440px 위치와 크기 전후 동일. 768/1024/1440px 헤더 스크린샷 PNG 바이트 전후 동일.
- Biome와 타입 검사 통과. 수정 후 전체 Vitest 421개 통과 및 하네스 검사 2개 5초 시간 초과. maxWorkers=4 재시도에서도 동일. 해당 2개만 maxWorkers=1, testTimeout=15000으로 재실행하여 모두 통과(실제 총 2.86초). 테스트/하네스 설정 파일은 변경하지 않음.
- `.github/workflows/ci.yml`, `tests/e2e/admin-tabs.spec.ts` 및 기존 CI 관련 산출물은 보존함.
